    Harvesting and reuse

    • Catalogue. A DCAT 3 catalogue of every dataset and file: JSON-LD and Turtle. Every page links to it in its header, so harvesters can find it from any address.
    • Each dataset carries an identifier, title, description, keywords, licence, publisher, contact point (the contact form), modification date and version.
    • Search engines. This page describes each dataset with schema.org markup, which dataset search services read.
    • Direct access. Files are served with permission for other websites to fetch them, so other portals and tools can read them directly.
    • Vocabulary. Concepts are published as SKOS, so other glossaries and catalogues can link to them.
    • Updates. Files change only with a release. The version and date are in every file's catalogue entry and on What's new.

    This is a prototype, not an official government catalogue. Where data repeats GOV.UK guidance, the GOV.UK page is the authority. The sources it draws on are catalogued separately in sources.jsonld.
