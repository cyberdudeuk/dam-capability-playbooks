# User research bundle: DAM capability playbooks

> **How to read this.** Facts marked V were read from this repository on 20 November 2026. Assumptions, measures and risks are proposals written for this kit, not findings. U means unconfirmed. Where another document in this repository already covers a topic, this one links to it rather than repeating it.

This project shares its users with the other cross-government data management projects, so it relies on one shared user research bundle rather than a copy: **EST-UR-001 (estate user research bundle; master kept in the private cdo-connect-hub repository)**. This file adds what is specific to this project.

## Evidence this project can rely on
- A cross-government data management discovery (13 structured workshops with 13 departments, June 2025). Its main findings: guidance is scattered and pitched too high, people need practical how-to help (playbooks, templates, examples), and they need access to peers and experts.
- Exploratory interviews across 10 public sector organisations in 2026. Their main finding: the opportunity is less about more guidance and more about helping people find, understand and act on what already exists, from whatever starting point their organisation is at.
- A rapid review of six earlier studies on guidance (December 2025), which found fragmentation and lack of practical detail in all six.

**Limits:** most participants were data professionals in central departments. Arm's length bodies, devolved administrations, local government, non-specialists and disabled users are under-represented. Treat every need as a hypothesis for anyone outside the groups asked.

## Users of this project
- Chief data officers and lead policy coordinators
- Data owners and data stewards
- Catalogue managers
- Data quality leads

## Questions only field research with this project's users can answer
1. Can each user group complete their most common task here without help? (Usability, with assistive technology.)
2. Where do they start (Google, GOV.UK, an intranet, a colleague, Copilot), and does this project surface there?
3. What would make them trust it, given it is not official? (Status, sources, review dates.)
4. What do they do when the site doesn't answer them?

## Field research scope for this project
- At least 6 participants per round across the user groups above, including at least 2 from arm's length bodies and at least 2 disabled participants.
- Task-based sessions on the live site, phone and desktop.
- Run through the shared participant pool and consent route described in EST-UR-001, not separately, to avoid participant fatigue.
- No personal data in this repository: findings are published as themes with session codes, never names.
