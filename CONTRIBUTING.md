# Contributing

Thank you for helping improve the playbooks.

1. For a question or a small correction, use the [contact form](https://cyberdudeuk.github.io/dam-capability-playbooks/contact.html) or "Report a problem with this page" at the foot of any page.
2. To propose a change, edit `content/playbooks.yaml` and open a pull request. Never edit the generated `site/` folder.
3. Every new fact needs a source and a provenance label: V (verified, with a date), P (practitioner material), O (synthesis), K (general knowledge) or U (unconfirmed).
4. Write in plain English and sentence case, following the GOV.UK style guide. Name roles, never people. Never include an email address.
5. Run the build, the checks and the tests before you open the pull request. The pull request template lists them.
6. If you fix a defect, add a check that would have caught it in the same pull request, and add the defect to the register in `content/playbooks.yaml`.

Discussions are the place for questions, shared practice and ideas that are not yet a change.
